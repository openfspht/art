## Files

| Need | File |
|---|---|
| Logo | [`logo/openfsp-logo.svg`](logo/openfsp-logo.svg) |
| Symbol only | [`logo/openfsp-mark.svg`](logo/openfsp-mark.svg) |
| Name only | [`logo/openfsp-wordmark.svg`](logo/openfsp-wordmark.svg) |
| Favicon | [`logo/favicon.svg`](logo/favicon.svg) |
| Profile image | [`logo/openfsp-avatar.svg`](logo/openfsp-avatar.svg), [`logo/openfsp-avatar-inverse.svg`](logo/openfsp-avatar-inverse.svg) |

The logo and the symbol also come in `-mono`, `-inverse` (dark backgrounds), `-black`
and `-white`. The wordmark comes in all of those but `-mono`, the avatar in default and
`-inverse` only, and the favicon as a single file.

PNG exports are in [`png/`](png/). Regenerate them from the SVG with
`scripts/export-png.sh` (requires `librsvg`).

## Colours

`#0B3B36` ink, `#E8A33D` accent, `#F5F2EA` chalk.

## Usage

Keep clear space around the logo, do not recolour or distort it, and read the
[brand book](BRAND.md) before anything unusual.
