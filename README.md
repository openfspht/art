## Files

| Need | File |
|---|---|
| Logo | [`logo/openfsp-logo.svg`](logo/openfsp-logo.svg) |
| Symbol only | [`logo/openfsp-mark.svg`](logo/openfsp-mark.svg) |
| Name only | [`logo/openfsp-wordmark.svg`](logo/openfsp-wordmark.svg) |
| Favicon | [`logo/favicon.svg`](logo/favicon.svg) |
| Profile image | [`logo/openfsp-avatar.svg`](logo/openfsp-avatar.svg), [`logo/openfsp-avatar-inverse.svg`](logo/openfsp-avatar-inverse.svg) |

Variants: `-mono`, `-inverse` (dark backgrounds), `-black`, `-white` for the logo and the
symbol; all but `-mono` for the wordmark. PNG exports are in [`png/`](png/), regenerated
with `scripts/export-png.sh` (requires `librsvg`).

Colours: `#0B3B36` ink, `#E8A33D` accent, `#F5F2EA` chalk.

Keep clear space around the logo, do not recolour or distort it, and see the
[brand book](BRAND.md) for anything else.
